# Quick Start Guide - Czech Keyboard Touch Typing Tutor

## Running the Application

### Step 1: Check Python Installation
```bash
python3 --version
```
You need Python 3.6 or higher.

### Step 2: Run the Application
```bash
python3 typing_tutor.py
```

### Step 3: Start Learning!
1. The application window opens showing the Czech QWERTZ keyboard
2. Click **"Start Exercise"** to begin
3. Type the displayed text
4. Watch your statistics update in real-time
5. Complete the exercise and click **"Next Exercise"**

## Understanding the Interface

### Color-Coded Keyboard
- **Pink** = Pinky fingers (malíčky)
- **Purple** = Ring fingers (prsteníčky)
- **Blue** = Middle fingers (prostředníčky)
- **Green** = Index fingers (ukazováčky)
- **Gold** = Thumbs (palce) for spacebar

### Real-Time Feedback
- **Green text** = Correct typing
- **Red text** = Mistakes
- **Yellow highlight** = Current key to press
- **WPM** = Words per minute (your speed)
- **Accuracy** = Percentage of correct keystrokes

## Learning Path

### Beginners (Levels 1-3)
Start with basic rows to learn finger placement
- Level 1: Home row (a s d f j k l ů)
- Level 2: Top row (q w e r t z u i o p)
- Level 3: Bottom row (y x c v b n m)

### Intermediate (Levels 4-6)
Practice real Czech words
- Level 4: Common words (být, mít, den)
- Level 5: Words with diacritics (může, již, věc)
- Level 6: More complex words (člověk, škola)

### Advanced (Levels 7-9)
Master full Czech typing
- Level 7: Advanced vocabulary
- Level 8: Complete sentences
- Level 9: Full texts

## Progress Tracking

Click **"View Progress Report"** to see:
- Total exercises completed
- Average WPM and accuracy
- Progress by level
- Improvement trends
- Recent exercise history

Your progress is automatically saved to `typing_progress.json`

## Tips for Success

1. **Sit properly**: Straight back, feet flat
2. **Home position**: Always return to home row (asdf jklů)
3. **Don't look down**: Watch the screen, not your fingers
4. **Use correct fingers**: Follow the color coding
5. **Accuracy first**: Speed comes with practice
6. **Practice daily**: 15-30 minutes is ideal
7. **Take breaks**: Rest your hands every 20 minutes

## Czech Diacritics

The application trains you on all Czech diacritics:
- ě, š, č, ř, ž (háčky)
- ý, á, í, é, ú (čárky)
- ů (kroužek)

## Troubleshooting

### Can't type Czech characters?
Make sure your keyboard is set to Czech (QWERTZ) layout in your operating system.

### Windows: 
Settings → Time & Language → Language → Add Czech

### Linux:
System Settings → Region & Language → Add Czech

### macOS:
System Preferences → Keyboard → Input Sources → Add Czech
